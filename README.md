# 社团报销材料自动化生成

上传按规范命名的发票（可选订单截图），自动生成三个报销文件：

1. **【支出单】姓名+活动事由.xlsx** — 支出单（Excel）
2. **【报销说明】姓名+活动事由.docx** — 报销说明（Word）
3. **【发票】【订单明细】姓名+活动事由.docx** — 发票与订单截图汇总（Word）

## 运行方法

```bash
# 安装依赖（首次）
pip install -r requirements.txt

# 启动
python app.py
```

浏览器打开 **http://127.0.0.1:5000**

## 使用流程

1. 填写**报销人姓名、学号、联系电话、活动事由**（所属部门默认「校团委社团管理部」）。
2. 上传发票（PDF / JPG / PNG，可多选），可选上传对应的订单截图。
3. 点「**开始解析**」→ 网页自动从发票**文件名**解析出明细，可逐条核对、修改。
4. 点「**生成并下载三个文件**」→ 打包下载 zip。

## 发票命名规范

文件名按 **物品+数量+单价+金额** 命名，用 `+` 分隔，例如：

- `手机支架+1个+20元+20元.pdf`
- `胸针+6个+3.79元+22.76元.pdf`
- `打车费+1次+25.5元+25.5元.pdf`（名称含「打车/滴滴/出租车」等关键词时，费用类别自动识别为「打车费」，否则为「采购费」）

解析规则：最后三段依次为 **数量 / 单价 / 金额**，剩余部分为**物品名称**（名称里可含 `+`）。金额为权威值，单价缺省时按 `金额 ÷ 数量` 反推。

## 生成内容说明

- **支出单**：自动填日期、票据张数；活动编号/项目号留空；所属部门固定「校团委社团管理部」；事由摘要 = 购买物品+数量；金额与发票严格一致；备注 = 单价；金额合计自动转人民币大写。
- **报销说明**：叙事两段（时间+活动、用途+金额），正文后可改；表格列「序号/项目/数量/单价/金额」。
- **发票订单明细**：一张发票 + 对应订单截图，循环排列。

## 目录结构

```
├── app.py            # Flask 服务与接口
├── extractor.py      # 文件名解析、PDF 渲染、类别识别
├── generator.py      # 三个文件的生成逻辑
├── money.py          # 金额格式化、人民币大写转换
├── static/index.html # 网页前端
├── templates/        # 三个模板文件（支出单模板、报销说明模板、发票订单明细参考）
├── uploads/          # 上传缓存（运行时生成）
└── output/           # 生成结果（运行时生成）
```
